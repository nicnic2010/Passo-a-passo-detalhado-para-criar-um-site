GITHUB

📁 Passo 1: criar o repositório

O repositório funciona como a pasta principal onde todos os arquivos do projeto ficarão armazenados.

1

Entrar no GitHub

Abra o navegador e entre na sua conta do GitHub. Depois de entrar, procure a página inicial da sua conta.

2

Procurar o botão de criação

Na página do GitHub, procure o símbolo +.

+

↓

New repository

Em algumas telas, também é possível encontrar o botão chamado New dentro da área de repositórios.

3

Escolher o nome

Procure o campo chamado:

Repository name

Nesse campo, escreva o nome que será utilizado para identificar o projeto.

meu-site-educativo
4

Criar o repositório

Depois de escolher o nome, desça até o final da página e procure o botão:

Create repository

Depois de tocar nesse botão, o repositório será criado.

ORGANIZAÇÃO

📄 Passo 2: criar os arquivos

Cada tipo de código deve ser colocado no arquivo correspondente.

📁 meu-site

├── 📄 index.html

├── 🎨 style.css

├── ⚙️ script.js

└── 🎥 video.mp4

1

Encontrar Add file

Dentro do repositório, procure o botão chamado:

Add file ↓ Create new file
2

Criar o HTML

No campo onde aparece o nome do arquivo, escreva exatamente: 

index.html

Abaixo do nome existe uma área grande para escrever o conteúdo do arquivo. É nessa área que o código HTML será colocado.

3

Salvar o arquivo

Depois de escrever o código, role até encontrar:

Commit changes

Esse botão salva as alterações dentro do repositório.

4

Criar os outros arquivos

Repita o mesmo processo para criar:

🎨 style.css ⚙️ script.js

Atenção: o nome deve ser escrito exatamente dessa forma.

ESTRUTURA

🧱 Passo 3: construir o HTML

O HTML deve ser escrito dentro do arquivo index.html.

1. A primeira linha 

<!DOCTYPE html>

Essa linha informa ao navegador que o documento utiliza HTML5.

2. A tag html 

<html lang="pt-BR">

</html>

Essa tag envolve todo o conteúdo do site. O atributo lang="pt-BR" informa que o conteúdo está em português do Brasil.

3. Criar o head 

<head>

</head>

O head guarda informações importantes sobre a página, mas essas informações não aparecem como conteúdo principal para o visitante.

4. Permitir caracteres especiais 

<meta charset="UTF-8">

Essa linha ajuda o navegador a mostrar corretamente caracteres como: ç, ã, é e ô.

5. Adaptar para celular 

<meta
    name="viewport"
    content="width=device-width,
    initial-scale=1.0"
>

Essa configuração ajuda o site a se adaptar melhor a telas de diferentes tamanhos, como celulares e computadores.

6. Escolher o título da aba 

<title>
    Meu site educativo
</title>

O texto colocado dentro da tag title aparece na aba do navegador.

🔗 7. Conectar o CSS

Ainda dentro do head, escreva: 

<link
    rel="stylesheet"
    href="style.css"
>

link: cria uma conexão com outro arquivo.

rel="stylesheet": informa que o arquivo conectado é uma folha de estilos.

href="style.css": informa o nome do arquivo CSS.

8. Criar o body 

<body>

</body>

Tudo que aparece para o visitante deve ser escrito dentro do body.

9. Criar um título 

<h1>
    Lentes no nosso dia a dia
</h1>

A tag h1 cria o título principal da página.

10. Criar um texto 

<p>
    Este é um texto explicativo.
</p>

A tag p cria um parágrafo.

CONEXÃO

🏷️ Como utilizar classes

As classes ajudam a identificar elementos para que eles possam receber estilos no CSS.

HTML 

<section
    class="inicio"
>

</section>
↔

CSS 

.inicio {

    background:
        purple;

}

No HTML, a classe recebe o nome inicio. No CSS, o mesmo nome é utilizado com um ponto na frente: .inicio.
